Recommended stack Electron desktop app. UI is plain HTML/JS in the renderer process; the main process owns a real SQLite database via node:sqlite (built into Node.js, no native rebuild step) stored as a file in the OS's standard per-app data folder. This replaces the earlier browser-based WASM/OPFS plan — a desktop app gives real filesystem access, so the workaround is no longer needed. The renderer never touches SQLite directly; it calls the main process over IPC. A one-click backup export (the SQLite file itself) lets you move data between machines. LLM API calls for the recommendation engine also run in the main process, keeping the API key out of the renderer entirely.
